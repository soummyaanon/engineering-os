Set up your coding agent once.

One command gives Claude Code, Codex, Cursor or any other coding agent the same vetted skills, safety guards and playbooks in every project, from frontend and backend to AI, research and go-to-market.

$

Run it in your terminal, then open a new Claude Code session and type /eos:map.


            
          

          
Paste it into any coding agent. It reads the installer first, works out its own agent id, and installs globally.

        

      

      
Needs git, Node.js and Python 3. Re-run the same command to update.

    


    

      
What it sets up

      

        
Frontend /eos:frontend
Build, polish and verify UI. Routes to Vercel's React rules, shadcn, impeccable, accessibility and performance audits.

        
Backend /eos:backend
APIs, Postgres, auth, payments and reliability, with a verification bar before anything is called done.

        
AI engineering /eos:ai
LLM features, agents, MCP servers, RAG, cost and latency. Pairs with /eos:evals for real test sets.

        
Reverse engineering /eos:reverse
Map unfamiliar codebases, undocumented APIs, protocols and competitor products, within authorized scope.

        
Research /eos:research
Decision-ready briefs with dated citations, plus a researcher agent for parallel digging.

        
Go-to-market /eos:gtm
Positioning, pricing, launch and demo playbooks, wired to Corey Haines' marketing skills.

      

    


    

      
Guards that run on every command

      
    
        
  • Blocks the unrecoverable. Wiping your home folder or a disk never runs.
    • 
        
  • Asks before the risky. Force-push, pushing to main, hard resets, destructive SQL, piping scripts into a shell, publishing and production deploys wait for your yes. Clearing node_modules doesn't.
    • 
        
  • Keeps secrets out of code. Real-looking API keys and database passwords written into source files trigger a check.
    • 
        
  • Briefs every session. It detects the project's stack and points the agent at the right playbook.
    • 
      

      
Guards run in Claude Code. Other agents get the skills and the working rules.

    


    

      
Grow it as you go

      
Ask your agent /eos:add with what you need. It searches the open skills directory, keeps only reputable sources, and records the pick so every machine you install on gets it. Or from the terminal:


# adopt a community skill
eos add owner/repo@skill --domain frontend
# write your own, live next session as /eos:stripe-webhooks
eos new-skill stripe-webhooks
# check what's installed
eos status
